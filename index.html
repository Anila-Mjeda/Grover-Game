THE LOCK'S RULE

What makes a key fit?

The circuit is built to test two conditions. It returns f(A,B) = 1 when both pass, and 0 otherwise. Knowing this test is how the oracle recognises a fit.

AND

This tiny rule is easy to solve by eye. The goal is to understand verification and amplification. Changing the rule starts a new round.

WHY THE BOOST WORKS

Four contributions, one output

The diffuser mixes the four search amplitudes. For one output row, multiply each input amplitude by its matrix weight, then add the four products. Products with the same sign reinforce; positive and negative products can cancel.

THE MATH UNDERNEATH

The actual matrix and full state vector

3 qubits · 8 components

Basis order: |000⟩, |001⟩, |010⟩, |011⟩, |100⟩, |101⟩, |110⟩, |111⟩. Each digit is a qubit’s basis value, ordered A, B, h. For example, |101⟩ labels A = 1, B = 0, h = 1. Eight labels are needed because 2³ = 8; zero entries are shown too.

⊗ combines operations on different qubits. I is the identity (no change). Z = diag(1, −1) multiplies helper-0 amplitudes by +1 and helper-1 amplitudes by −1. † means conjugate transpose; for a unitary gate it is the inverse. This checker is its own inverse. All amplitudes here are real.

Rows label output components; columns label input components. A row × the input vector gives one output amplitude. Scroll horizontally to see the whole equation.
