⊕ means XOR: when f = 1, toggle h; when f = 0, leave it alone. Applying the same toggle twice restores the original helper.

The coherent checker uses reversible logic. No candidate or helper is measured during the oracle. This helper-based implementation makes the mechanism visible; some phase-oracle circuits need no extra helper.

WHY THE BOOST WORKS

Four contributions, one output

The diffuser mixes amplitudes. Each input contributes a signed amount to the selected output. Matching signs reinforce; opposite signs cancel.

THE MATH UNDERNEATH

The actual matrix and full state vector

3 qubits · 8 components

Basis order: |000⟩, |001⟩, |010⟩, |011⟩, |100⟩, |101⟩, |110⟩, |111⟩. The bits are A, B, h, with helper h on the right.

⊗ combines operations on different wires. I leaves a wire unchanged; Z = diag(1, −1) changes phase. † denotes the inverse here. All amplitudes in this example are real.

Select a basis row to inspect its dot product. On a small screen, scroll the matrix horizontally.

When the helper begins and ends in |0⟩, these matrices describe the search register alone. The oracle matrix represents the complete check–mark–clear sequence, not its intermediate steps.

Does a phase flip alone help?

Compare three experiments. Each trial prepares a fresh |00⟩ search state, runs the chosen sequence, then measures A and B once.

The probabilities are exact for this ideal four-key, one-solution model. Counts in the uniform experiments fluctuate randomly. A single quantum measurement reveals one key, not the full state vector.
